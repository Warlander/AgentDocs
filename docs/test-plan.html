AgentDocs — Test Plan

Complete list of tests proposed before public release. Framework: vitest (TS-native, zero config, runs in Node). Each test listed with inputs and expected outputs. Nothing written yet — this is the spec for approval.

Prerequisite refactor (small): packages/server/src/index.ts calls serve() at module top level, so importing it starts listeners. Extract route construction into createApp(vaultDir) in a new app.ts; index.ts becomes a thin entry that calls createApp + serve. Tests then build apps against temp vault dirs on ephemeral ports. Pure code motion, no behavior change.

Unit-testable functions (slugify, stripHtml) move to a util.ts so they can be imported directly.
