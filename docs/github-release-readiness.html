AgentDocs — GitHub Release Readiness

Assessment of E:\Web\AgentDocs as of 2026-08-07. Scope: ~770 lines of TypeScript across server, web UI, and CLI, plus Docker packaging.

Verdict: not yet — but close. The code itself is release-quality: tight, secure-by-design for a local tool, no framework bloat. What's missing is everything around the code: license, tests, CI, and the trust signals strangers need before they clone. Roughly one focused day of work.

Security posture — good, but must be documented

The design is sound for an untrusted-HTML vault: documents served from a separate origin (:3001) with a restrictive CSP (default-src 'none', inline-only scripts/styles), git SHAs regex-validated before git show/diff, FTS query input escaped, slugs whitelisted (^[a-z0-9-]+$) so no path traversal. No injection holes found.
No authentication, by design — fine on 127.0.0.1, but docker-compose.yml sets HOST=0.0.0.0: anyone on the LAN can upload arbitrary HTML and read every doc. That's acceptable for a personal tool if the README says so in bold with a "do not expose to a network you don't trust" warning. Undocumented, it becomes someone's CVE-shaped issue report. Also worth one line: uploads have no size limit.
